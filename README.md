# 🚀 DevLog - Blog de Tecnologia

Um layout dinâmico e moderno de blog com suporte a **Modo Escuro (Dark Mode)** e microinterações no CSS para melhorar a experiência do usuário (UX).

## 📌 Funcionalidades
* **Hover Interativo:** Os cartões (`<article>`) aumentam levemente de tamanho e ganham destaque na sombra ao passar o mouse.
* **Dark Mode:** Suporte a tema escuro com sombras customizadas (tom azulado brilhante) para manter a sensação de profundidade.
* **Layout Responsivo:** Desenvolvido com CSS Grid e Flexbox.

## 🛠️ Tecnologias Utilizadas
* HTML5
* CSS3 (Variáveis CSS, CSS Grid, Transitions, Pseudo-classes)
* JavaScript Vanilla
# 🚀 DevLog - Blog Multi-páginas de Tecnologia

Um blog de tecnologia completo com múltiplos arquivos HTML, navegação dinâmica, suporte a **Modo Escuro (Dark Mode)** e microinterações no CSS.

## 📌 Páginas do Projeto
* **Início (`index.html`):** Destaques principais e ultimos artigos publicados.
* **Artigos (`articles.html`):** Listagem completa de publicações com filtros por categoria.
* **Sobre (`about.html`):** Apresentação do projeto, visão e perfil do autor.

## 🛠️ Tecnologias Utilizadas
* HTML5 (Estrutura semântica e multi-páginas)
* CSS3 (Variáveis CSS, CSS Grid, Transitions, Pseudo-classes)
* JavaScript Vanilla (Alternância de tema e sincronização no `localStorage`)
